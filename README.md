# การวิเคราะห์และจัดการข้อมูลด้วย MySQL: กรณีศึกษา 3 ระบบ

จนถึงสร้างฐานข้อมูลจริงและเขียน Query ดึงข้อมูลเชิงวิเคราะห์

## ระบบที่ออกแบบ

โปรเจกต์นี้ออกแบบฐานข้อมูลสามระบบที่มีลักษณะความสัมพันธ์ต่างกัน
เพื่อครอบคลุมรูปแบบปัญหาที่หลากหลาย

| ระบบ | ลักษณะเด่น |
|---|---|
| ระบบการสั่งซื้อสินค้าออนไลน์ | ความสัมพันธ์ซับซ้อนหลายชั้น มีการชำระเงิน จัดส่ง รีวิว และคืนสินค้า |
| ระบบการจองที่จอดรถยนต์ | การจองตามช่วงเวลา ตรวจสอบสถานะพื้นที่ และคิดค่าบริการ |
| ระบบการลงทะเบียนเรียน | ความสัมพันธ์แบบ M:M ระหว่างนิสิตกับรายวิชา |

## ขั้นตอนการทำงาน

แต่ละระบบผ่านกระบวนการเดียวกันครบทั้ง 5 ขั้นตอน

### 1. ทำความเข้าใจระบบ

วิเคราะห์ขั้นตอนการทำงานของระบบจริง ระบุข้อมูลที่ต้องจัดเก็บในแต่ละขั้นตอน
และกำหนดข้อกำหนดทางธุรกิจ (Business Rules) เช่น

- ลูกค้าสมัครได้ 1 บัญชีเท่านั้น แต่เพิ่มที่อยู่จัดส่งได้หลายที่อยู่
- ต้องชำระเงินภายใน 24 ชั่วโมงหลังสั่งซื้อ มิฉะนั้นคำสั่งซื้อจะถูกยกเลิก
- คืนสินค้าได้ภายใน 3 วันหลังได้รับสินค้า และคืนเงินภายใน 3 วันทำการ

### 2. สร้าง Entity Relationship Diagram

ออกแบบ ER-Diagram พร้อมอธิบายเหตุผลของทุก Attribute
ว่าเก็บไว้เพื่ออะไรและนำไปใช้งานอย่างไร

### 3. แปลงเป็น Relational Database Model

แปลงโมเดลเชิงแนวคิดเป็นโมเดลเชิงสัมพันธ์ กำหนด Primary Key และ Foreign Key

### 4. Normalization

ทำบรรทัดฐานข้อมูลจาก **1NF → 2NF → 3NF** ครบทุกตารางของทั้งสามระบบ
พร้อมแสดงขั้นตอนการแยกตารางและเหตุผลในแต่ละระดับ

### 5. Data Dictionary

จัดทำพจนานุกรมข้อมูลระบุชนิดข้อมูล ขนาด และเงื่อนไขการตรวจสอบความถูกต้อง
รวมถึงตรรกะการตรวจสอบวันที่ เช่น การแยกเดือนที่มี 30 กับ 31 วัน
และการตรวจสอบวันที่ 29 กุมภาพันธ์ในปีอธิกสุรทิน

## ตัวอย่าง SQL Query

เขียน Query เชิงวิเคราะห์ระบบละ 10 คำสั่ง โดยใช้การเชื่อมตารางหลายชั้น
ร่วมกับ `GROUP BY`, `HAVING`, `ORDER BY`, `BETWEEN` และฟังก์ชันรวม
`SUM()` / `COUNT()`

ตัวอย่างโจทย์ที่แก้

- หาลูกค้าที่ซื้อสินค้าประเภทเครื่องดื่ม เรียงตามจำนวนที่ซื้อมากไปน้อย
- หาที่อยู่ของลูกค้าที่มีการจัดส่งไม่สำเร็จ (เชื่อม 8 ตาราง)
- หาลูกค้าที่สั่งซื้อสินค้าหมวดขนมขบเคี้ยวและมีอายุระหว่าง 20-30 ปี
- หายอดรวมของแต่ละร้านค้าในช่วงเวลาที่กำหนด

```sql
SELECT First_name, Last_name, Product_name, Quantity
FROM id_card, customers, orders, product
WHERE id_card.ID_card = customers.ID_card
  AND customers.ID_Customer = orders.ID_Customer
  AND orders.Product_code = product.Product_code
  AND product.Product_type = "Beverage"
ORDER BY Quantity DESC;
```
